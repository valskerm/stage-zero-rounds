# Stage Zero Rounds

Round-by-round standings for the Stage Zero FPL Classic League (657059).
The season is split into four rounds (GW1–10, 11–20, 21–30, 31–40) and points reset each round.

- Round 1 score = overall total at GW10
- Round 2+ score = current total − total captured at the end of the previous round

`data.json` is refreshed twice a day by a GitHub Action (`.github/workflows/update-data.yml`).
You can also run it by hand: Actions tab → "Update league data" → Run workflow.
